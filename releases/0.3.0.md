Put the current player on an existing disc, watch auto-play count down, and try sample discs from Test Disc.

## Create

- Upgrade an existing BeebSID disc to this SIDPLAY and fill in missing play times
- Firefly converts and plays
- Golden Axe converts and plays its first song

## Player

- Auto-play shows a yellow **AUTO MM:SS** countdown on the last line
- **,** / **.** (or **‹ ›**) change song and leave auto-play; **Return** still skips and stays in auto-play
- **Down** stops on the last SID instead of walking onto a blank row

## Disc Creator

- **Gallery** on Test Disc: click a screenshot to boot a sample disc
- Test Disc plays floppy loading sounds so a long boot is not mistaken for a crash
- **Upgrade** on that popup writes this player onto a loaded disc when it is behind
- A disc that is not BeebSID shows **Cannot load disc** instead of a broken emulator
- A progress bar above the log shows how far Create has got
- Convert and pack run in the background so the window stays usable
- f4 is remapped to Options (it used to open Choose files). Tune preview clips and Test Disc floppy noises are on or off there, kept in this browser
