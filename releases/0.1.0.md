First release of the standalone Node.js SID → BeebSID toolchain: in-memory create pipeline, BeebAsm SIDPLAY, and the Disc Creator web UI.

## Create

- Convert C64 SIDs to `.bbcsid` and pack a bootable SSD
- Hash-selected patches (Head Over Heels, RoboCop, RoboCop 3)
- Skip tunes that fail relocate, overflow SIDPLAY RAM, or are unpatched RSIDs; pack the rest
- `./create` / `.\create.cmd` first-run bootstrap

## Player

- BeebAsm SIDPLAY (BBC) and SIDPELK (Electron)
- Tunes load at `$19F8`; player at `$6000` (Electron `$4800`)

## Disc Creator

- Drag-and-drop SIDs, preview in jsbeeb + FastSID
- Hosted at https://fozretro.github.io/beebsidtools/
- `./app` / `.\app.cmd`

## Notes

- Unpatched RSID files need a manual hash patch (see RoboCop)
- Playing on a real Beeb needs BeebSID hardware or Pi1MHz emulation
